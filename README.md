# tap_website

Static four-page site for Tapestry Research Group. Tabs along the top switch between pages: About Us, Services, Meet the Team, Contact.

Placeholder copy is marked `[Placeholder]`; replace it, the email address in `contact.html` and the team cards in `team.html`.

Preview locally: open `index.html`, or run `python3 -m http.server` and visit http://localhost:8000.
Deploy: push to GitHub, then Settings > Pages > Deploy from branch > `main` / root.
